# Episodio 1.3 · ¿Funciona con datos nuevos?

**Objetivo:** Evaluar un modelo con datos que no vio y compararlo con una línea base.

## Lo que ya sabes en Excel → cómo se hace en Python

| En Excel | En Python |
|---|---|
| Separar filas para comprobar | `train_test_split()` |
| `=ABS(real - proyectado)` y `=PROMEDIO()` (`AVERAGE`) | `mean_absolute_error(y_prueba, prediccion)` |
| Comparar con el promedio | Línea base: `y_entreno.mean()` |
