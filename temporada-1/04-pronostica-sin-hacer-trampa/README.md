# Episodio 1.4 · Pronostica sin hacer trampa

**Objetivo:** Pronosticar solo con lo que se sabe antes, y compararlo con reglas simples.

## Lo que ya sabes en Excel → cómo se hace en Python

| En Excel | En Python |
|---|---|
| Usar solo los meses anteriores | Columnas como `promedio_6` |
| Proyectar con el pasado y comparar con el futuro | `tabla[tabla["mes"] < "2025-07"]` |
| Promedio de los últimos meses | Línea base con `mean_absolute_error()` |
