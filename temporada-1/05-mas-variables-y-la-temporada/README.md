## Lo que ya sabes en Excel → cómo se hace en Python

| En Excel | En Python |
|---|---|
| Índice del mes con una tabla dinámica | `por_mes / por_mes.mean()` |
| `=BUSCARV()` (`VLOOKUP`) del índice | `.map(indice)` |
| Una columna por cada valor de un texto | `pd.get_dummies()` |
