# Episodio 1.8 · Cuando el 85 % de aciertos no sirve

**Objetivo:** Evaluar un clasificador sin dejarse engañar, y elegir el umbral según el costo.

## Lo que ya sabes en Excel → cómo se hace en Python

| En Excel | En Python |
|---|---|
| Tabla dinámica de real contra predicho | `pd.crosstab(real, marcadas)` |
| Porcentaje de aciertos | `accuracy_score()` |
| De lo marcado, ¿cuánto era cierto? | `precision_score()` |
| De lo cierto, ¿cuánto marqué? | `recall_score()` |
