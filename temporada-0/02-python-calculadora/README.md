# Episodio 0.2 · Python como calculadora

**Objetivo:** Variables, tipos de datos (número, texto, fecha), listas, diccionarios y cómo leer un error sin miedo.

## Lo que ya sabes en Excel → cómo se hace en Python

| En Excel | En Python |
|---|---|
| Celda con nombre | Variable |
| Una columna | Lista |
| Una ficha o fila | Diccionario |
| `#¡VALOR!`, `#¡DIV/0!` | Mensajes de error (`TypeError`, `ZeroDivisionError`) |
