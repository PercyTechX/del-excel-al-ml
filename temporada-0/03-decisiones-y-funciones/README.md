# Episodio 0.3 · Decisiones, repeticiones y funciones

**Objetivo:** Tomar decisiones, repetir un cálculo y crear tus propias fórmulas.

## Lo que ya sabes en Excel → cómo se hace en Python

| En Excel | En Python |
|---|---|
| `=SI()` (`IF`) | `if` / `else` |
| Arrastrar la fórmula hacia abajo | `for` |
| `=SUMAR.SI()` (`SUMIF`), `=CONTAR.SI()` (`COUNTIF`) | `for` con `if` y un acumulador |
| Una fórmula que reutilizas | Una función con `def` |
