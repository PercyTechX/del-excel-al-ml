# Episodio 0.4 · pandas I: abre tu Excel en Python

**Objetivo:** Leer archivos CSV y Excel, verlos, filtrarlos y ordenarlos.

## Lo que ya sabes en Excel → cómo se hace en Python

| En Excel | En Python |
|---|---|
| Abrir un archivo | `pd.read_csv()`, `pd.read_excel()` |
| Filtros | `df[df["ciudad"] == "Lima"]` |
| Ordenar de A a Z | `df.sort_values()` |
