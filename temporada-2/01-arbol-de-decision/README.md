# Episodio 2.1 · Árbol de decisión: tu `=SI()` anidado, pero aprendido

**Objetivo:** Entrenar un árbol, leer sus ramas y usar cada hoja como un nivel de riesgo.

## Lo que ya sabes en Excel → cómo se hace en Python

| En Excel | En Python |
|---|---|
| `=SI()` (`IF`) anidado | `DecisionTreeClassifier(max_depth=3)` |
| Leer la fórmula | `plot_tree(arbol, ...)` |
| Porcentaje por regla | `arbol.predict_proba(x)[:, 1]` |
