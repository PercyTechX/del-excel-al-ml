# Episodio 2.2 · Cuando el árbol se aprende todo

**Objetivo:** Medir con un cupo de vigilancia, ver el sobreajuste y elegir el tamaño con un grupo de validación.

## Lo que ya sabes en Excel → cómo se hace en Python

| En Excel | En Python |
|---|---|
| Una regla con mil excepciones | Un árbol sin `max_depth` |
| Revisar solo una parte cada día | `parte_encontrada(fecha, real, probabilidad)` |
| Probar en otro periodo | Un grupo de `validacion` |
